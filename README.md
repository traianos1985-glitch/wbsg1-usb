# WB-SG1-8G Keypad (USB)

Σελίδα ελέγχου για τη γεννήτρια WB-SG1-8G από κινητό ή υπολογιστή.
Ένα μόνο αρχείο: `index.html`, χωρίς εξαρτήσεις.

## Χρήση

1. Άνοιξε τη σελίδα σε Chrome ή Edge (HTTPS).
2. Σύνδεσε τη γεννήτρια με USB (στο κινητό με OTG).
3. Πάτα **Connect** και διάλεξε τη συσκευή FTDI.

- Android: χρησιμοποιεί WebUSB. Κλείσε πρώτα εφαρμογές όπως το Serial USB Terminal.
- Υπολογιστής: χρησιμοποιεί Web Serial.
- Ρυθμίσεις σύνδεσης: 9600 baud, 8N1, χωρίς flow control.

## Εκτός ορίων

- Δεν περιλαμβάνει sweep.
- Το «LAST SENT» δείχνει την τελευταία τιμή που στάλθηκε, δεν διαβάζει τη συσκευή.
- Το format του `$F` για το CH1 (9 ψηφία) είναι εκτίμηση. Επιβεβαίωσέ το από το Debug.
